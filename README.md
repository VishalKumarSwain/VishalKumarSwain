### 🔬 About me

I combine **formal methods** with **machine learning and LLMs** to make software verification smarter and more scalable.

- 🧠 **Neuro-symbolic SMT solving** over bit-vector logic — entrant at **SMT-COMP 2026**
- 🛡️ **CBMC-based bounded model checking** and **MC/DC coverage** for safety-critical embedded C/C++ — JRF at **DRDO**
- 🤖 **LLM fine-tuning** (LoRA, StarCoder2) for coverage-driven test generation
- 🚗 **ML-based test prioritization** for self-driving cars — **IEEE ICST 2026** tool paper
- 🎯 Next: formal verification and **AI-assisted EDA**
